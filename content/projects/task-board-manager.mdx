## Overview

Task Board Manager is a kanban-style task app — columns, cards, drag-and-drop, priorities, and due dates. I built it as a portfolio demo specifically to show a different half of my toolkit: **Angular on the frontend and Express on the backend**, deliberately contrasting the Next.js/NestJS stack behind [Squirrel Away](./squirrel-away.mdx). Same TypeScript rigor, different frameworks.

## What it shows

**Angular component architecture.** Standalone components, typed models/interfaces, routing, a service layer, and Angular CDK powering the drag-and-drop between columns.

**Express API design.** A clean REST surface for task CRUD plus status moves and a reset-to-seed endpoint:

```
GET    /api/tasks           # list
POST   /api/tasks           # create
PUT    /api/tasks/:id       # update
DELETE /api/tasks/:id       # delete
PUT    /api/tasks/:id/move  # move to another status/column
POST   /api/tasks/reset     # reset to initial data
```

**Deployment awareness.** The repo ships with a Dockerfile, docker-compose, nginx config, and Kubernetes manifests — the app is containerized and deploys to Railway.

**UI/UX.** A custom SCSS design system, responsive layout, modal forms for task creation/editing, and priority + due-date support on cards.

## Why it's in the portfolio

Range. Squirrel Away proves depth in the React/Next ecosystem; this proves I'm equally comfortable in Angular and can stand up a containerized, deployable full-stack app end to end.
